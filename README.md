# Hey, I'm Luca 👋

 I'm a frontend developer who enjoys building things and figuring out how they should work along the way.

🚀 I'm currently building **Mira**, an interactive atlas for discovering the art, history, and people behind places, starting with Rome. Explore the map, read short stories, and follow links to Wikipedia to dive deeper.

👉 [**www.explorewithmira.app**](https://www.explorewithmira.app/)

 I mostly work with **TypeScript, React, Next.js, and Tailwind CSS**. I care about good UX, clear code, and shipping something that works before making it fancy.

 As AI gets better at writing code, I'm focusing more on architecture and **Domain-Driven Design**. My goal is to get better at shaping systems, making good decisions, and giving coding agents the right direction — so we can complement each other instead of just generating more code.

🔍 Lately, I've been playing with:

- 🤖 AI-assisted products and workflows
- 🗺️ Maps and location-based experiences
- 🏛️ Cultural and historical discovery
- 💡 New ways to make complex information easier to explore

 I like small iterations, honest code, and tools that actually help people.

🎨 When I'm not writing code, I'm probably learning something about art, history, or the places around us.
